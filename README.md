# Meus Sites Favoritos

## Sobre o projeto

Este projeto foi desenvolvido como atividade da Agenda 12 - Desenvolvimento de Sistemas, com o objetivo de praticar os conceitos introdutórios de HTML5.

A página apresenta cinco sites favoritos, com seus respectivos nomes, imagens e links para acesso.

## Como executar

1. Baixe ou clone este repositório.

2. Abra a pasta do projeto.

3. Abra o arquivo `index.html` em um navegador, como Google Chrome ou Microsoft Edge.

5. Para visualizar as imagens carregadas de endereços externos, mantenha uma conexão com a internet.
